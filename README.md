# Telegram Music Bot

Асинхронный Telegram-бот для поиска музыки, кэширования отправленных треков по Telegram `file_id`, локального топа, избранного и распознавания голосовых/аудио/видео сообщений. Имеет панель администратора.

## Что уже работает

- `/start` с русской клавиатурой.
- Поиск по локальному каталогу с fuzzy matching от 70%.
- Загрузка через отдельный `yt-dlp` адаптер, повтор до 3 раз и конвертация в MP3 через ffmpeg.
- Сохранение `file_id` и счётчика прослушиваний.
- «По исполнителю» — играбельный список (каталог + источник аудио) с кнопками, а не просто текст.
- «Песни исполнителя», локальный топ и inline-кнопки.
- Избранное: под **каждым** отправленным аудио есть кнопки «❤️» (в избранное) и «❌» (убрать трек и вернуться к поиску). «💔» — убирает из избранного. Список избранного открывается командой `/like`, кнопкой «Избранное» или командой `/favorites`.
- «Топ 100» и «Локальный топ» показываются по 10 треков на страницу с кнопками ⏪ / ⏩; поиск — по 8 с кнопками ◀️ / ▶️. Каждая страница редактирует то же сообщение, новые сообщения не плодятся.
- «Топ 100» через Spotify Global Top 50 (или встроенный список из 100 треков), с постраничной выдачей и кнопками ⏪ / ⏩.
- Распознавание `voice`, `audio`, аудио/видео-документов и видео-сообщений через ffmpeg + shazamio.
- **Поиск с постраничной выдачей**: найденные треки показываются по несколько штук на страницу с кнопками ◀️ / ▶️, когда результат большой.
- `GET /health` для мониторинга.
- Supabase cache через `SUPABASE_URL`/`SUPABASE_KEY`, PostgreSQL через `DATABASE_URL` и локальный SQLite fallback.

### Панель администратора (`/admin`)

Владелец (Telegram ID в `ADMIN_ID` / `ADMIN_IDS`, по умолчанию `8377297659`) и пользователи, которым он выдал права, могут открыть панель командой `/admin`. Если ID ещё не настроен, бот ответит на `/admin` вашим числовым ID — его и нужно вписать в `ADMIN_ID`. Команда `/id` печатает ваш ID в любой момент. Значения читаются из переменных окружения или из файла `.env` (кавычки, пробелы, комментарии и несколько ID через запятую понимаются):

```dotenv
ADMIN_ID=123456789
ADMIN_IDS=123456789,987654321
# ADMIN_USERNAMES=my_username
```

- **Статистика** — сколько пользователей всего начали бота, сколько активно за 7 дней, сколько заблокировали бота (авто-определение по недоставленным сообщениям), сколько заблокировано вами, сколько треков в каталоге, сколько обязательных каналов и сколько администраторов. Если агрегирующий запрос к базе не удался, панель считает те же цифры по списку пользователей и показывает их, а не ошибку. Повторное нажатие на кнопку не «ломает» панель.
- **Обязательные каналы** — админ добавляет/удаляет каналы. Принимаются `@username`, `https://t.me/username`, `t.me/username`, ссылки на сообщения, частные каналы `https://t.me/c/1234567890/1`, пригласительные ссылки `https://t.me/+AbCd…` и числовые ID вида `-1001234567890`. Права бота проверяются через `getChatAdministrators`, затем через `getChatMember`; если Telegram не смог ответить, канал всё равно добавляется с предупреждением (больше никаких ложных «убедитесь, что бот админ»). Пока пользователь не подписан на все каналы, он не может пользоваться ботом: при каждой попытке он видит кнопки каналов и «✅ Я подписался — проверить».
- **Блокировки** — заблокировать/разблокировать пользователя (по ID или @username) или быстро из списка пользователей.
- **Администраторы** — владелец может выдать/забрать права администратора другому пользователю.
- **Голосовой поиск** — включить/выключить распознавание на лету.

Для проверки подписки бот должен быть **администратором** этих каналов (Telegram не разрешает проверять членство иначе).

### Хранилище и «Локальный топ»

«Локальный топ» строится из каталога бота: туда попадает каждый скачанный или найденный трек. Без `DATABASE_URL`/Supabase каталог — это SQLite в `MUSIC_DB_PATH` (по умолчанию `/tmp/music-bot/music.sqlite3`). На Replit/Render `/tmp` очищается при каждом рестарте, поэтому для постоянного топа укажите путь на постоянном диске, например `MUSIC_DB_PATH=/home/runner/music.sqlite3`.

### Голосовой поиск (запуск)

Чтобы «Поиск по голосу» заработал, на сервере должны быть установлены:

```bash
# системный пакет ffmpeg (обязателен для декодирования аудио/видео)
apt-get install -y ffmpeg

# python-зависимость shazamio (уже в requirements.txt)
pip install -r requirements.txt
```

Если модуль не установлен, бот аккуратно сообщает об этом, а не падает. Переменная `ENABLE_SHAZAM=true` включает распознавание при старте.

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="..."
python -m music_bot.main
```

В Replit токен хранится в Secrets. Для Render задайте `BOT_TOKEN`, `ADMIN_ID` (или `ADMIN_IDS`), а также опционально `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SUPABASE_URL` и `SUPABASE_KEY`; пример `render.yaml` уже добавлен.

## База данных

Для Supabase сначала выполните `supabase/schema.sql` в SQL Editor проекта Supabase (файл создаёт таблицы `songs`, `favorites`, `users` и `required_channels`). Если таблица недоступна, бот пишет причину в лог и временно использует локальное хранилище в `/tmp`.

## Источник аудио и права

`ENABLE_YTDLP_DOWNLOADS` включён для совместимости с исходным ТЗ, но использовать загрузчик нужно только для аудио, на которое у владельца бота есть права или разрешение источника. Для каталога с лицензированной музыкой замените `YouTubeProvider` на адаптер вашего разрешённого провайдера, не меняя handlers и базу.
