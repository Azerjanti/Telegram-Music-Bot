# Telegram Music Bot

Асинхронный Telegram-бот для поиска музыки, кэширования отправленных треков по Telegram `file_id`, локального топа, избранного и распознавания голосовых/аудио/видео сообщений. Имеет панель администратора.

## Что уже работает

- `/start` с русской клавиатурой.
- Поиск по локальному каталогу с fuzzy matching от 70%.
- Загрузка через отдельный `yt-dlp` адаптер, повтор до 3 раз и конвертация в MP3 через ffmpeg.
- Сохранение `file_id` и счётчика прослушиваний.
- «Песни исполнителя», локальный топ и inline-кнопки.
- Избранное: кнопка «❤️» под треком добавляет в избранное, «💔» — убирает. Список избранного открывается командой `/like`, кнопкой «Избранное» или командой `/favorites`.
- «Топ 100» через Spotify Global Top 50 (или локальный fallback).
- Распознавание `voice`, `audio`, аудио/видео-документов и видео-сообщений через ffmpeg + shazamio.
- **Поиск с постраничной выдачей**: найденные треки показываются по несколько штук на страницу с кнопками ◀️ / ▶️, когда результат большой.
- `GET /health` для мониторинга.
- Supabase cache через `SUPABASE_URL`/`SUPABASE_KEY`, PostgreSQL через `DATABASE_URL` и локальный SQLite fallback.

### Панель администратора (`/admin`)

Владелец (Telegram ID в `ADMIN_IDS`, по умолчанию `8490020175`) и пользователи, которым он выдал права, могут открыть панель командой `/admin`:

- **Статистика** — сколько пользователей всего начали бота, сколько активно за 7 дней, сколько заблокировали бота (авто-определение по недоставленным сообщениям) и сколько заблокировано вами.
- **Обязательные каналы** — админ добавляет/удаляет каналы (по @username или ссылке). Пока пользователь не подписан на все каналы, он не может пользоваться ботом: при каждой попытке он видит кнопки каналов и «✅ Я подписался — проверить».
- **Блокировки** — заблокировать/разблокировать пользователя (по ID или @username) или быстро из списка пользователей.
- **Администраторы** — владелец может выдать/забрать права администратора другому пользователю.
- **Голосовой поиск** — включить/выключить распознавание на лету.

Для работы каналов бот должен быть **администратором** этих каналов (Telegram не разрешает проверять членство иначе).

### Голосовой поиск (запуск)

Чтобы «Поиск по голосу» заработал, на сервере должны быть установлены:

```bash
# системный пакет ffmpeg (обязателен для декодирования аудио/видео)
apt-get install -y ffmpeg

# python-зависимость shazamio (уже в requirements.txt)
pip install -r requirements.txt
```

Если модуль не установлен, бот аккуратно сообщает об этом, а не падает. Переменная `ENABLE_SHAZAM=true` включает распознавание при старте.

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="..."
python -m music_bot.main
```

В Replit токен хранится в Secrets. Для Render задайте `BOT_TOKEN`, `ADMIN_IDS`, а также опционально `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SUPABASE_URL` и `SUPABASE_KEY`; пример `render.yaml` уже добавлен.

## База данных

Для Supabase сначала выполните `supabase/schema.sql` в SQL Editor проекта Supabase (файл создаёт таблицы `songs`, `favorites`, `users` и `required_channels`). Если таблица недоступна, бот пишет причину в лог и временно использует локальное хранилище в `/tmp`.

## Источник аудио и права

`ENABLE_YTDLP_DOWNLOADS` включён для совместимости с исходным ТЗ, но использовать загрузчик нужно только для аудио, на которое у владельца бота есть права или разрешение источника. Для каталога с лицензированной музыкой замените `YouTubeProvider` на адаптер вашего разрешённого провайдера, не меняя handlers и базу.
