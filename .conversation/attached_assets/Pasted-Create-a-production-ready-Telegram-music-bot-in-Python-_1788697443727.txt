BOT FEATURES:

1. /start command:
- Send welcome message:
  "🎵 Добро пожаловать в музыкальный бот!
   Выбери одну из опций ниже:"
- Keyboard buttons:
  [🔍 Поиск песни] [🎵 Топ 100]
  [🎤 Поиск по исполнителю] [📻 Локальный топ]
  [🎙 Поиск по голосу]

2. SONG SEARCH:
- User sends any text
- First search Supabase (fuzzy match rapidfuzz 70%+)
- If found: send audio by file_id instantly
- If not found:
  a) Search YouTube: "{query} official audio"
  b) Download with yt-dlp best quality
  c) Convert to mp3 192kbps with ffmpeg
  d) Send as audio to user
  e) Save file_id to Supabase
- After sending show inline buttons:
  [🎤 Песни исполнителя] [▶️ Следующая]

3. ARTIST SEARCH:
- Bot asks: "Напишите имя исполнителя 🎤"
- Show all songs by artist from DB
- If less than 5: search YouTube top 10
- Paginated list 5 per page

4. TOP 100:
- Fetch Spotify Global Top 50
- Numbered list with inline buttons
- Click → download and send

5. LOCAL TOP:
- Supabase ORDER BY play_count DESC LIMIT 50
- Numbered list
- Click → send instantly

6. VOICE RECOGNITION:
- User sends voice message or audio file
- Use shazamio to identify
- Show: "🎵 Найдена: {title} - {artist}"
- Auto send full song

ERROR HANDLING:
- Download fails → retry 3 times → 
  "Песня не найдена 😔"
- Shazam fails → 
  "Песня не распознана, попробуйте ещё раз 🎙"
- Spotify fails → use cached top 100 from Supabase
